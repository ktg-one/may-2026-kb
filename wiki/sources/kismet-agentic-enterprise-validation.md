## What this document operationalises

### Diagnostic Discovery — the gateway product

A **non-invasive audit** that delivers value *before* the prospect commits to a multi-year contract:

> [!example] Digital Health Check → Traffic Light Report
> Agentic workflows crawl the prospect's website, lead funnels, and public documentation **before the first meeting**, identifying manual nodes and technical friction. Output is a Traffic Light Report:
> - 🔴 **Red** — High-risk / entirely manual → prioritize for automation or risk mitigation
> - 🟡 **Amber** — Optimizable through better integration → schedule for refinement
> - 🟢 **Green** — Already effectively automated → monitor for agentic drift

Also: **Shadow AI footprint** mapping — discovery platforms inspect financial transactions, network traffic, browser usage to surface unauthorized AI tool usage.

### G.U.A.R.D.I.A.N.S. Persistence Framework

Three-tier memory architecture that turns stateless models into learning systems:

| Memory Type | Function |
|-------------|----------|
| **Episodic** | Immutable audit log of all interactions / agentic decisions |
| **Semantic** | Factual enterprise knowledge, ontologies, user preferences (the "encyclopedia") |
| **Procedural** | Codified task patterns and reusable workflows |

Solves "session amnesia" and "hallucination cascades."
