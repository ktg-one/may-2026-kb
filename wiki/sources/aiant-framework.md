## What it is

A framework for evaluating LLMs on honesty, fabrication necessity, and platform-level transparency. Derives "transparency > fabrication > complexity" as an accounting argument under lab efficiency mandates.

The onboard file contains the Python-pseudocode derivation (definitions, collapse proof, cost model, harm model). The all-tests file contains the operational tooling — model probes, pique tests, and stealth MBTI tasks.
