## CONSOLIDATION OPPORTUNITIES

### Kismet CRM Button Pattern
Complete-Button, Escalate-Button, and SyncToGoogle all share the same architecture: `Webhook → Validate → Notion lookup → Action → Respond`. Could be consolidated into a single **KISMET-CRM-Router** workflow with a switch node on button type. Pros: single endpoint, shared error handling, easier maintenance. Cons: larger single workflow.

### Error Handling
Merge "Error" and "KISMET-Error-Log" into one workflow that does both: logs to Sheets AND sends email for critical errors.
