# TASK: Lee Monarch Accounting & Advisory — 3x Brand Kit Directions

## Context
- **Client**: Vivienne — solo practitioner, premium tax/CFO advisory
- **Business**: Lee Monarch Accounting & Advisory
- **Existing logo**: LM monogram (navy + gold), serif wordmark. She's open to recolouring.
- **Brief keywords**: Premium, Strategic, Confident, Elegant, Future-focused, Authority-driven
- **Anti-brief**: No generic accounting blue-grey, no boring corporate, no cold tone
- **Client note**: She mentioned pink. She wasn't joking. Take it seriously.
- **Reference standard**: See `ktg-port.pdf` — each kit should be structured like those brand boards (hero mood, palette, typography hierarchy, logo variants, tagline zone)
- **Services**: Tax Planning, CFO Advisory, Structuring, Due Diligence
- **Audience**: High-value clients, not compliance-level bookkeeping

## Deliverable
Four distinct brand direction visual boards. Each must include:

1. **Direction name** (2-3 word mood label, e.g. "Gilded Authority")
2. **Colour palette** — 3-4 hex codes with named roles (primary, secondary, accent, neutral)
3. **Typography pairing** — heading font + body font (Google Fonts only for web implementation)
4. **Typography hierarchy demo** — heading, subheading, body text sample
5. **Mood keywords** — 5-6 descriptors for the visual feel
6. **Mood image direction** — describe 2-3 types of photography/texture that sell this direction (for sourcing later)
7. **Logo treatment notes** — how the existing LM monogram adapts to this palette
8. **Where it sits** — one line on what kind of client this direction attracts

## The Four Directions

### Kit 1: "Refined Heritage"
- Evolve the existing navy + gold but push warmer, less "bank lobby"
- Think: deep navy, warm brass/champagne, ivory
- Serif-forward typography, classic but not stuffy
- Mood: established firm, generational wealth advisory, quiet confidence

### Kit 2: "Modern Luxe"
- Navy + blush/rose pink + cream or soft white
- This is the one she actually wants. Make it undeniably premium so she feels bold choosing it.
- Think: Valentino pink meets financial advisory
- Clean sans-serif or modern serif, editorial feel
- Mood: contemporary, feminine authority, stands out from every other accounting firm

### Kit 3: "Dark Monarch"
- Dark/moody palette — charcoal or near-black + warm copper/bronze + off-white
- High contrast, editorial, magazine-cover energy
- Strong typographic hierarchy, possibly a display font for headings
- Mood: power, sophistication, unapologetic premium positioning

### Kit 4: "Future Monarch"
- High-contrast palette — bold, punchy, not muted
- Quirky but professional — future-tech energy without looking like a SaaS startup
- Think: unexpected colour combos that still read "premium advisory"
- Forward-looking, innovative, "this isn't your parents' accountant"
- Mood: future-focused, confident, category-defying, tech-savvy

## Output Format
Use branding plugins to produce full visual brand boards (not just specs). Each board should match the quality/structure of the reference portfolio (`ktg-port.pdf`): hero mood area, colour palette with hex codes, typography pairing with hierarchy demo, logo treatment, overall vibe — one visual page per direction.

## Constraints
- Google Fonts only (must work in Elementor + web)
- Palettes must pass WCAG AA contrast on body text
- No stock photo sourcing — describe the mood image direction, don't link images
- Don't touch the LM monogram design itself — just describe recolouring
